# website-ppdb

Website PPDB Pesantren Tahfidz Telaga Al Kautsar (SMP Islam Terpadu Berasrama).

## Fitur & Program
- Profil Pesantren & 3 Nilai Utama (Karakter Qur'ani, Disiplin & Kemandirian, Wawasan Global)
- Program Unggulan: Tahfidz Intensif, IT & Coding/Robotik Dasar, Bahasa Asing, Leadership & Akhlak
- Formulir Pendaftaran Online & Integrasi WhatsApp Resmi PPDB

## Tech Stack
- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Panduan Menjalankan Secara Lokal

1. **Install dependensi**:
   ```bash
   npm install
   ```

2. **Jalankan server pengembangan**:
   ```bash
   npm run dev
   ```

3. Buka browser di [http://localhost:3000](http://localhost:3000).
